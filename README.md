# صلاحية للأعمال — Salahiya Business

نظام كامل لتتبع تواريخ انتهاء صلاحية المنتجات، مصمم للمطاعم والمقاهي والمخابز والصيدليات.

A complete system for tracking product expiry dates, built for restaurants, cafés, bakeries, and pharmacies.

---

## طريقة التشغيل

1. فك ضغط الملف
2. افتح `index.html` في أي متصفح
3. سجّل دخول:
   - البريد: `admin@salahiya.app`
   - كلمة المرور: `admin123`

لا يحتاج تثبيت، لا يحتاج سيرفر. يعمل فوراً.

## المميزات

- واجهة عربية RTL بتصميم عصري داكن
- سجل تفتيش كامل — من أضاف ماذا ومتى
- تقارير امتثال جاهزة للطباعة PDF
- إدارة المنتجات بأرقام الدفعات والموردين
- تسجيل درجة حرارة الاستلام
- تنبيهات ذكية قبل انتهاء الصلاحية
- متوافق مع جميع الجوالات
- يعمل بدون إنترنت بعد التحميل

## محتويات الملف

- `index.html` — التطبيق الرئيسي
- `manifest.json` — بيانات PWA
- `service-worker.js` — دعم العمل دون إنترنت
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — الأيقونات

## الترخيص

استخدام غير محدود. لا يُسمح بإعادة بيع الكود كما هو.
